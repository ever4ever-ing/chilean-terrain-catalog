# **App Name**: Chilean Terrains Catalog

## Core Features:

- Terrain Catalog Display: Display a searchable catalog of terrains with attributes like region, area, price, and other relevant details.
- Filtering and Sorting: Implement filtering and sorting options based on different attributes (region, price range, area, etc.).
- Map Integration: Display each terrain on a map using its coordinates.

## Style Guidelines:

- Primary color: Earthy tones like browns and greens to reflect the natural landscapes of Chile.
- Secondary color: Light gray or beige for backgrounds to provide contrast and readability.
- Accent: A vibrant blue (#29ABE2) to highlight interactive elements and calls to action, inspired by the Chilean sky and coastline.
- Clean and responsive layout to ensure usability on different devices.
- Use clear and recognizable icons to represent terrain attributes and filter options.
